# Examples

| File | What it shows |
|---|---|
| `quickstart.py` | tiny class-incremental EWC run on CPU (`python examples/quickstart.py`) |
| `custom_method.py` | subclassing `MethodPluginABC` and registering a plugin by name |

Both run in seconds on CPU with the `toy` dataset and no downloads. For real
protocols see `configs/exp/` and `configs/baselines/`; for the CLI see
`docs/usage.md`.
